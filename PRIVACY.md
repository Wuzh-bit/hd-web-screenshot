# 隐私政策 / Privacy Policy

**网页截图助手 / Web Screenshot Assistant**

最后更新 / Last updated: 2026-07-31

---

## 中文

本扩展（网页截图助手）仅在用户主动点击工具栏图标或按下快捷键（Alt+Shift+S）时运行。

截图过程完全在用户本地浏览器内完成，生成的图片仅保存在用户自己的设备上或复制到系统剪贴板。

本扩展：

- 不会将任何网页内容、截图或用户信息上传到任何服务器；
- 不会收集、存储或共享任何个人数据；
- 不使用任何远程代码，所有功能均依赖本地打包的脚本实现。

我们不会也无法访问您通过本扩展产生的任何截图或浏览内容。

---

## English

This extension (Web Screenshot Assistant) runs only when the user actively clicks the toolbar icon or presses the keyboard shortcut (Alt+Shift+S).

The screenshot process is performed entirely within the user's local browser. The resulting image is only saved on the user's own device or copied to the system clipboard.

This extension:

- does not upload any web page content, screenshots, or user information to any server;
- does not collect, store, or share any personal data;
- does not use any remote code; all functionality relies on locally bundled scripts.

We cannot and do not access any screenshots or browsing content you create with this extension.
